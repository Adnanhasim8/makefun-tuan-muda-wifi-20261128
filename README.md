# One Word for Your Wi-Fi

Entry for the make.fun competition `u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72`: one word describing my Wi-Fi, judged pairwise on funny and true.

The word is **Microwave** — every home Wi-Fi dies the moment someone reheats lunch, because the microwave kills the 2.4 GHz signal. A concrete image, not a mood word, and funny as a network name without ever explaining itself. Picked from 18 scored candidates (see the table in `main.py`); runner-up was Peekaboo.

## Run

Python 3.13, standard library only, no network:

```sh
python3 main.py
```

Writes exactly `Microwave` (no trailing newline) to `/output/entry.txt`. For a private output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/tuan-muda-wifi-out python3 main.py
```
